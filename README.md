# 科烽智能 CSV 编辑器

一个 Windows 桌面小工具，用来查看和修改 **CSV 表格文件**（`.csv`，就是那种用逗号分隔、
可以用 Excel 或 WPS 打开的表格文件）。

打开程序 → 拖入文件 → 改完保存，**无需联网、无需注册、免费使用**。

## 三个特点

| 特点 | 说明 |
| --- | --- |
| **稳定性高，不闪退** | 打开几十万行的表格也不崩溃 |
| **性能优秀，不卡顿** | 实测 10 万行表格约 2 秒即可正常操作，占用内存约 300 MB |
| **功能易用，不复杂** | 只有一条主线：打开 → 修改 → 保存，不用学 |

### 和 Excel / WPS 最大的区别：数据不会变形

Excel 和 WPS 打开 CSV 时会自作主张地转换内容，常见问题：

| 原始内容 | 用 Excel / WPS 打开后 | 用本工具打开 |
| --- | --- | --- |
| `00123`（带前导零的编号） | 变成 `123`，前导零丢失 | 仍是 `00123` |
| `2024-03-15` | 可能被改成 `2024/3/15` 等格式 | 保持原样 |
| `12345678901234567890`（超长数字） | 可能被四舍五入 | 保持原样 |

**本工具把每个格子都当纯文本看待，绝不擅自转换**；保存时也会保留文件原本的编码与
换行格式。因此特别适合处理工号、编号、卡号、日期、金额等"格式不能变"的数据。

## 怎么安装

### 第 1 步：拿到程序

向研发部门索取 **`CSVEditor.exe`**（单个文件，约 0.3 MB），放到任意目录即可，
例如 `D:\工具\CSVEditor\`。绿色版，不用安装、不写注册表、不产生垃圾文件。

### 第 2 步：安装运行环境（只需一次）

程序需要微软的 **.NET 10 桌面运行时**。如果电脑上还没装，双击程序时会弹出一个英文
提示框（里面有下载链接），按下面做一次即可：

1. 打开 <https://dotnet.microsoft.com/download/dotnet/10.0>
2. 下载 **Desktop Runtime**（桌面运行时）的 **x64** 版本
3. 双击安装，一路"下一步"；装完重新双击 `CSVEditor.exe` 就能用了

> 如果打不开这个网址或没有安装权限，请把这一页给 IT 或研发部门看，让他们帮忙装一次。

### 第 3 步（可选）：发送到桌面

右键 `CSVEditor.exe` → 发送到 → 桌面快捷方式。

## 怎么用

### 打开文件（三种方式，任选其一）

- 把 CSV 文件**直接拖进程序窗口**
- 点击「浏览文件」或工具栏「打开」，选择文件
- 在 Excel 里复制一片数据，打开程序后点「粘贴」

> 首次使用可以点「试用示例数据」，打开一份演示表格练手，不会影响你自己的文件。

### 修改数据

| 想做的事 | 怎么做 |
| --- | --- |
| 改一个格子 | 双击它，改完按 `Enter` |
| 把格子的内容清空 | 选中后按 `Delete` |
| 删掉几行 | 选中这些行，点工具栏「删除行」 |
| 增加一行 | 点「插入行」，或在选中行上按 `Alt+Enter` |
| 增加一列 | 点「插入列」 |
| 改列名 | 双击表头的列名 |
| 撤销刚才的操作 | `Ctrl+Z`（可连续撤销） |

### 查找和替换

按 `Ctrl+F` 打开查找框（或工具栏「查找 / 替换」）：

- 查找、替换内容（`Ctrl+H` 直接跳到替换）
- 可勾选"区分大小写""全字匹配"做精确查找
- 会实时显示"共找到多少处"

### 保存结果

- **保存**（`Ctrl+S`）：覆盖原来打开的那个文件
- **另存为**（`Ctrl+Shift+S`）：存成新文件，原文件不动

### 导出成其它格式

菜单「文件 → 导出」可另存为 **Excel（.xlsx）**、**JSON**、**TSV** 等格式。
用本工具导出的 Excel 文件，里面的编号、日期同样不会被 Excel 改动。

## 常见问题

**问：文件会被上传到网上吗？**
不会。程序完全在本机运行，没有任何联网功能，断网也能正常使用。

**问：能打开 Excel 文件（.xlsx）吗？**
不能，本工具只处理 `.csv` / `.tsv` / `.txt` 这类文本表格。需要的话先在 Excel 里
用「另存为 → CSV（逗号分隔）」转一下。

**问：能筛选、排序吗？**
目前版本还没有这两个功能，聚焦在"打开 → 修改 → 保存"这条主线上。

**问：打开大文件时程序好像卡住了？**
几十万行的文件在载入时需要几秒，期间窗口可能短暂无响应，请稍等。
单次建议不超过 100 万行。

**问：改完忘了保存就关了？**
程序检测到有未保存的改动时会弹窗询问，选「是」即可保存。

**问：换了台电脑要重新设置吗？**
不需要。程序会在第一次使用时记住你偏好的字号，换电脑重新设置一次即可。

## 出问题了怎么办

1. 记下**报错文字**和**当时在做什么操作**（截图最好）
2. 如果程序打不开，先确认第 2 步的运行环境是否装好
3. 把上面信息发给研发部门，他们会查看日志文件：
   `%TEMP%\csveditor-crash.log`（在文件资源管理器地址栏粘贴此路径即可打开）
